# Support and Bug Reports

MiliUI is developed around the Miliastra creator community.

## Questions, feedback, and setup help

The primary community discussion location is the official Miliastra Discord. MiliUI discussion will use a dedicated thread/forum location there once the public beta opens.

Use Discord first for:

- setup questions;
- "is this a bug?" questions;
- API usage questions;
- feature ideas;
- screenshots and videos;
- general feedback;
- showing what you built with MiliUI.

## Confirmed bugs

Once a problem appears to be a MiliUI bug, open a GitHub Issue using the bug-report template.

Please include:

- MiliUI version;
- MiliUI Manager version, if applicable;
- Miliastra version/build if known;
- PC/controller/other input device;
- resolution and aspect ratio when the problem is visual;
- affected MiliUI component;
- minimal reproduction steps;
- relevant Lua code;
- complete error/stack trace;
- screenshot or short video when useful.

Do not include account credentials, private project secrets, or other sensitive information.

## Feature requests

Feature requests can start in Discord. Concrete requests that are ready to track can use the GitHub feature-request template.

## Security or privately reportable problems

Do not publish sensitive security information in a public Issue. Contact the MiliUI maintainer privately through the official Miliastra Discord.
